# Future Improvements

## Purpose
This document captures worthwhile follow-on work that should stay out of the current AudienceMind baseline. These items are intentionally deferred so the product stays focused on a stable analyst workflow and a maintainable core.

## Deferred Product And Platform Work
- Add role-based access control, audit trails, and multi-user collaboration flows.
- Add project templates, reusable scenario playbooks, and domain-specific starter packs.
- Add richer graph analytics such as time-window diffs, causal chain views, and evidence scoring.
- Add report export bundles with evidence manifests and traceable provenance packages.
- Add evaluation harnesses for simulation quality, report quality, and model/provider comparison.
- Add cost, latency, and token usage dashboards across providers and long-running jobs.
- Add streaming report assembly and richer live execution telemetry in the analysis workspace.
- Add more advanced survey and interview tooling for large simulation populations.
- Add deployment packaging for stricter enterprise environments, including hardened observability and operational dashboards.
- Revisit optional localization only after the English-only baseline is stable and compliant.

## Defer These Until After V1
- Public marketing pages and external demo experiences.
- Experimental model-specific optimizations that reduce portability.
- Additional graph or simulation backends beyond the first supported production path.
